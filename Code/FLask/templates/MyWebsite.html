Reflection 1: Multi-Modal System Development

Applying Sustainability Principles to Create Viable Systems

In the Multi-Modal System Development project, I helped design a platform integrating EEG, image, and audio data for real-time emotion analysis. The project emphasized sustainability by focusing on system viability, user needs, and resource optimization.

I learned the importance of balancing accuracy and efficiency. Integrating data streams enhanced robustness but increased computational complexity, requiring algorithm optimization and efficient pipeline design.

Additionally, we prioritized ethical responsibility, ensuring data privacy and security, essential for sustainable system design.

Reflection 2: ChartPPT Development

Professional Practice within Intercultural and Global Contexts

Working on the ChartPPT Development project involved creating a tool that dynamically generates presentation-ready charts integrated with PowerPoint using Python APIs. Key challenges included:

  • Designing cross-platform compatible interfaces
  • Balancing complex functionality with user accessibility
  • Ensuring scalability for large datasets

This project emphasized cultural awareness through accommodating regional preferences for chart styles. It reinforced the value of modular coding practices and iterative user testing with diverse audiences.
